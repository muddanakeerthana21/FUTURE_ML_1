# FUTURE_ML_1
📈 AI-Powered Sales Forecasting Dashboard (Future Interns - ML Task 1)
📌 Overview
This project was completed as part of Future Interns - Machine Learning Internship (Task 1). The goal of this task is to build a predictive analytics dashboard that helps retail businesses forecast future sales using historical transaction data.

->The project includes:

-Data cleaning and preprocessing
-Monthly sales trend analysis
-Time-series forecasting using Facebook Prophet
-An interactive Power BI Dashboard with actual and forecasted sales trends
🎯 Problem Statement
Retail businesses require accurate sales forecasting to plan inventory, marketing, and business operations. This project forecasts future sales trends based on past sales data and presents insights through an interactive dashboard.

✅ Features
✅ Data cleaning and preprocessing using Python (Pandas)

✅ Monthly sales aggregation and preparation for forecasting

✅ Sales forecasting using Prophet time series model

✅ Forecast export to CSV for BI integration

✅ Power BI dashboard with:

-Actual monthly sales trend
-Forecasted sales trend
-KPI cards (Total Sales, Avg Monthly Sales)
-Filters by Category, Region, and Date
-Key insights and recommendations for decision making

🛠️ Tech Stack / Tools Used
Python (Pandas, Prophet)
Jupyter Notebook
Power BI Desktop
CSV Dataset (Superstore / Retail Sales dataset) 

🚀 How to Run This Project:
1️⃣ Install Python Libraries:-
pip install pandas prophet
2️⃣ Run the Notebook:
Open Jupyter Notebook and run:

jupyter notebook
Run Sales_Forecasting.ipynb to:

load dataset
generate monthly sales
train forecasting model
create sales_forecast.csv
3️⃣ Open Power BI Dashboard
Open Power BI Desktop and load:

superstore.csv
sales_forecast.csv
Then open the .pbix file:

AI_Powered_Sales_Forecasting_Dashboard.pbix
📌 Output Files
sales_forecast.csv → forecast results from Prophet (ds, yhat)
Power BI Dashboard (.pbix) → interactive report visualization
